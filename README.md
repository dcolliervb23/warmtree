# warmtree

A pool of pre-warmed git worktrees for parallel AI coding agents.

Loving the awesomeness that is git, but hating the overhead that is cloning a new worktree branch or regular branch of any repo, but especially massive ones, and the time lag, timeouts, etc that can result therefrom, Warmtree exists to help aid in solving that issue, keeping multiple "slots" aka branches that are kept "warm" or fast-forwarded to origin main/master or close to it.
